## Resources

**Books**

- [Brunton & Kutz — *Data-Driven Science and Engineering* (2nd ed., Cambridge)](https://databookuw.com/) — The key book for ML + fluids: SVD/POD, DMD, ROMs, physics-informed ML. Site has videos and code for every section.
- Kutz, Brunton, Brunton & Proctor — *Dynamic Mode Decomposition* (SIAM) — Full treatment of DMD.

**Videos & courses**

- [Steve Brunton — *Singular Value Decomposition* / POD series](https://www.youtube.com/results?search_query=Steve+Brunton+singular+value+decomposition)
- [Steve Brunton — *Dynamic Mode Decomposition* lectures](https://www.youtube.com/results?search_query=Steve+Brunton+dynamic+mode+decomposition)

**Papers**

- [Taira et al. (2017) — *Modal Analysis of Fluid Flows: An Overview* (AIAA J.)](https://arxiv.org/abs/1702.01453)

**Docs & tools**

- [PyDMD (Python DMD library)](https://github.com/PyDMD/PyDMD)
